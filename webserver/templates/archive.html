Cette page permet de générer une archive (fichier zip) regroupant les données à conserver à l'issue de la session, conformément aux règles de minimisation et de conservation des données personnelles (RGPD).

Contenu de l'archive

  • planning_oraux.csv — planning final des oraux (candidat, matière, salle, examinateur, horaires)
  • emargements.csv — preuves de signature des examinateurs (sans les images, déjà incluses dans les PDF ci-dessous)
  • journal_audit.json — journal d'audit chaîné par hash (intégrité vérifiable, voir Vérifier l'intégrité des données)
  • documents/ — fiches d'émargement de toutes les salles, régénérées au moment du téléchargement (signatures des candidats incluses) : {% if salles %}
      {% for salle in salles %}
    • Salle {{ salle }}
      • {% endfor %}
    {% else %} aucune salle disponible pour le moment {% endif %}
  • LISEZMOI.txt — résumé du contenu de l'archive et date de génération

Volontairement absents de cette archive

Par souci de minimisation des données, l'archive ne contient pas :

  • les mots de passe ni les clés de connexion (candidats, examinateurs, loges)
  • les fichiers CSV bruts d'inscription (listes d'inscription importées en amont)
  • les autres PDF générables à la demande depuis la page algo (papillons, fiches candidats/loges, liste générale des oraux)
